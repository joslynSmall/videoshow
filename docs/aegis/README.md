# Aegis Workspace

This workspace holds the dual baselines and design specs for `videoshow`.

- `BASELINE-GOVERNANCE.md`: baseline rules and review protocol for this project.
- `baseline/`: initial and current baseline snapshots (evidence, not authority).
- `specs/`: proposed and approved design specs.
- `INDEX.md`: document index.

`videoshow` is a Node.js HTTP service that turns video page URLs into playable streams and serves a browser player.
